## Описание проекта 
Создана игровая сцена Forest, сцена ввода имени игрока, создан игровой персонаж и функционал перемещения на кнопки, сбор грибов и перемещение на другие локации.

## Стек проекта 
* **Игровой движок / Платформа:** Godot Engine 4.x 
* **Язык программирования:**  GDScript / C# 
* **Дополнительные инструменты:** 

## Что было использовано в проекте 
* **Узлы (Nodes):** ColorRect, CharacterBody2D, VboxContainer, HboxContainer, TileMapLayer, PointLight2D, CanvasLayer и другие
* **Паттерны / Подходы:** global.gd, ui.gd, menu.gd, teleport.gd, mushrooms.gd, movement_logic.gd
* **Ресурсы:** спрайты по заданию, спрайты из интернета.
